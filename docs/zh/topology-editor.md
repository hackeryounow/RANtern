# 拓扑编辑器

## 概述

拓扑编辑器是 RANtern 的核心交互界面，基于 AntV X6 图引擎实现。用户通过拖拽方式构建核心网拓扑，一键部署为 Docker 容器集群。

## 界面布局

```
┌──────────────────────────────────────────────────────────┐
│  工具栏 (Deploy / Stop / Destroy / Save / Load / YAML)    │
├────────┬─────────────────────────────────────────────────┤
│        │                                                 │
│ 组件   │            画布区域 (AntV X6)                    │
│ 面板   │         拖拽网元 · 连线 · 平移缩放              │
│(可拖宽)│                                                 │
│        │                                                 │
├────────┴─────────────────────────────────────────────────┤
│  日志控制台 (多标签页 · 实时日志 · ANSI 颜色)             │
└──────────────────────────────────────────────────────────┘
```

## 组件面板

左侧面板列出所有可用网元，按类别分组：

- **5G Control Plane** — AMF, SMF, NRF, SCP, AUSF, UDM, UDR, PCF, NSSF, BSF, CHF
- **5G User Plane** — UPF
- **4G EPC** — MME, SGW-C, SGW-U, HSS, PCRF
- **Data / Storage** — MongoDB, WebUI
- **RAN / External** — gNodeB, eNodeB, UE (5G), UE (4G), Ext DN
- **Networking** — Bridge (L2)

面板支持：
- **搜索过滤** — 输入关键词快速定位网元
- **拖拽添加** — 将网元拖入画布
- **自定义节点** — 点击 "Custom Node" 添加任意 Docker 镜像
- **宽度调整** — 拖拽面板右边缘调整宽度（160px ~ 480px）

## 画布操作

| 操作 | 方式 |
|------|------|
| 添加网元 | 从左侧面板拖入画布 |
| 移动网元 | 拖拽节点 |
| 连线 | 从一个节点的端口拖到另一个节点的端口 |
| 平移画布 | 鼠标中键拖拽 / 空白处拖拽 |
| 缩放 | 鼠标滚轮 |
| 删除 | 选中后按 Delete 键 |
| 查看属性 | 点击节点/连线，右侧弹出 Inspect 面板 |

## 工具栏功能

| 按钮 | 功能 |
|------|------|
| ▶ Deploy | 部署当前拓扑（创建并启动所有容器） |
| ⏹ Stop | 停止所有已部署容器 |
| 🗑 Destroy | 销毁所有容器 + 网络 + 卷 |
| 💾 Save | 保存拓扑到服务器 |
| 📂 Load | 从服务器加载已保存拓扑 |
| 📋 YAML | 查看/编辑当前拓扑的 YAML 定义 |
| 🏷 Toggle Labels | 显示/隐藏连线标签 |
| 🐳 Images | 打开 Docker 镜像管理抽屉 |

## 节点配置

点击已放置的节点，右侧弹出配置侧边栏（NFConfigSidebar），可编辑：

- **PLMN 配置** — MCC, MNC
- **网络切片** — S-NSSAI (SST/SD), DNN, CIDR
- **接口 IP** — 各逻辑接口的 IP 地址
- **自定义环境变量** — 键值对形式

## 日志控制台

部署后，点击任意节点可在底部控制台查看实时日志：

- 多标签页并行查看多个节点日志
- 支持 ANSI 颜色渲染
- 支持暂停/恢复日志流
- 支持清空日志
- 关闭单个标签或一键关闭全部

## 拓扑模板

通过工具栏 "Topologies" 按钮打开模板抽屉：

- 查看已保存的拓扑列表
- 一键加载模板到画布
- 查看拓扑 YAML 定义（全屏弹窗）
- 删除不需要的拓扑

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Delete` / `Backspace` | 删除选中节点/连线 |
| `Ctrl + S` | 保存拓扑 |
| `Ctrl + =` / `Ctrl + -` | 放大/缩小 |
| `Ctrl + 0` | 重置缩放 |
