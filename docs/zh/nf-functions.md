# 3GPP 网元功能

本篇依据 3GPP **TS 23.501**（5G 系统架构）介绍各核心网元（NF）的标准功能与主要职责，帮助理解拓扑中每个节点「做什么」。镜像、端口、挂载等部署细节见 [网元组件介绍](/docs/nf-components)；各流程如何串联这些网元见 [核心网流程](/docs/procedures)。

> 说明：以下为功能性概述，章节号引用 TS 23.501 通用版本，不逐字摘抄规范原文。

## 5G 核心网网元（TS 23.501 §6.2）

### AMF — 接入和移动性管理功能（§6.2.1）

UE 接入核心网的第一个控制面锚点（N1/N2 终结点）。

- 注册管理：处理 UE 注册 / 去注册
- 连接管理：建立 UE 与核心网之间的信令连接
- 移动性管理：跟踪区更新、切换中的移动性事件
- 接入认证与授权：与 AUSF / UDM 协作完成鉴权
- 安全锚点：作为 NAS 信令加密 / 完整性保护的锚点
- 路由会话管理消息到 SMF

### SMF — 会话管理功能（§6.2.2）

负责 PDU 会话的控制面。

- PDU 会话的建立 / 修改 / 释放
- 为 UE 分配 IP 地址
- 选择并控制 UPF（通过 N4 / PFCP）
- 策略执行与 QoS 控制（与 PCF 交互）
- 下行数据通知与会话相关的 NAS 消息处理

### UPF — 用户面功能（§6.2.3）

5G 用户面的数据转发节点（N3 / N6 / N9）。

- 数据包的路由与转发（用户面数据锚点）
- 数据包检测与 QoS 流到 DRB 的映射
- 上行 / 下行流量统计与计费上报
- 下行数据缓冲与触发
- 作为 PDU 会话的锚点（会话 / 分支点）

### AUSF — 认证服务器功能（§6.2.4）

- 执行 UE 的 3GPP 接入认证（5G-AKA / EAP-AKA'）
- 与 UDM 协作获取认证向量
- 锚定安全上下文

### UDM — 统一数据管理（§6.2.5）

- 生成 3GPP 接入认证凭据
- 用户标识处理（SUPI / SUCI 解隐蔽）
- 签约数据管理
- 会话管理签约数据、接入授权
- 与 UDR 交互存取用户数据

### UDR — 统一数据仓库（§6.2.6）

- 存储签约数据、策略数据、结构化暴露数据
- 作为 UDM / PCF 的数据持久层（Nudr 接口）

### PCF — 策略控制功能（§6.2.7）

- 提供策略规则给控制面 NF（AMF / SMF）
- 会话 / 服务数据流的 QoS 与计费策略
- 移动性相关策略
- 从 UDR 读取策略签约数据

### NRF — 网络存储库功能（§6.2.8）

- 服务发现：维护可用 NF 实例及其支持的服务
- NF 注册 / 去注册 / 状态通知
- 向消费方 NF 返回目标 NF 实例（SBI 服务化的核心）

### NSSF — 网络切片选择功能（§6.2.9）

- 为 UE 选择服务的网络切片集合
- 确定允许的 NSSAI、映射到签约的 S-NSSAI
- 确定服务该 UE 的 AMF 集合

### BSF — 绑定支持功能（§6.2.10）

- 绑定 PCF 与 UE / 会话的对应关系
- 在多个 PCF 部署时，帮助消费方 NF 找到正确的 PCF

### CHF — 计费功能（§6.2.11）

- 在线 / 离线计费
- 接收来自 SMF 等 NF 的计费事件并生成计费记录

### SCP — 服务通信代理（§6.2.12）

- 在间接通信模型中代理 NF 间的 SBI 请求
- 提供 NF 选择、负载均衡、消息路由

## 4G EPC 网元对照（TS 23.501 §6.3 互操作映射）

平台同时支持 4G EPC。下表给出 EPC 网元与 5GC 网元的功能对应关系：

| 4G EPC 网元 | 功能 | 对应 5GC 网元 |
|-------------|------|---------------|
| **MME** | 移动性管理实体：NAS 信令、鉴权、承载管理 | AMF（+ SMF 的会话部分） |
| **SGW-C** | 服务网关控制面：承载 / 移动性锚点 | SMF |
| **SGW-U** | 服务网关用户面：数据转发 / 锚点 | UPF |
| **PGW-C** | PDN 网关控制面：IP 分配、策略 | SMF（+ PCF） |
| **PGW-U** | PDN 网关用户面：数据转发到 PDN | UPF |
| **HSS** | 归属用户服务器：签约 / 认证数据 | UDM（+ UDR / AUSF） |
| **PCRF** | 策略和计费规则功能 | PCF |

## 网元间接口（参考点）速查

| 接口 | 连接 | 主要用途 |
|------|------|----------|
| N1 | UE ↔ AMF | NAS 信令 |
| N2 | (R)AN ↔ AMF | NGAP 信令 |
| N3 | (R)AN ↔ UPF | GTP-U 用户面 |
| N4 | SMF ↔ UPF | PFCP 会话控制 |
| N6 | UPF ↔ DN | 数据网络出口 |
| N11 | AMF ↔ SMF | 会话管理信令 |
| N12 | AMF ↔ AUSF | 认证 |
| N8 / N10 | UDM ↔ AMF / SMF | 签约 / 会话数据 |
| N7 | SMF ↔ PCF | 策略 |
| Nnrf | NF ↔ NRF | 服务注册 / 发现（SBI） |

> SBI（Service Based Interface）：5GC 控制面网元通过基于 HTTP/2 的服务化接口互联，统一由 NRF 做服务发现。
