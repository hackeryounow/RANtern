# NF Components

## Image Model Overview

RANtern supports two core network implementations with different containerization strategies:

| Feature | Open5GS | Free5GC |
|---------|---------|---------|
| Image strategy | **Single image** + `COMPONENT_NAME` env var | **Per-NF image** `free5gc/<nf>:v4.0.1` |
| Image name | `docker_open5gs:v2.8.0-beta` | `free5gc/amf:v4.0.1`, etc. |
| Configuration | Mount `/mnt/<nf>/` dir, init script sed substitution | Mount `/free5gc/config/<nf>cfg.yaml` |
| Service discovery | Static IP + hardcoded config | NRF registration/discovery (SBI) |
| TLS certificates | Not required | Required (generated by NRF on startup, mounted at `/free5gc/cert`) |

## Open5GS Network Functions

### Image Info

```
Image: swr.cn-north-4.myhuaweicloud.com/cn_5gc/docker_open5gs:v2.8.0-beta
Size: ~1.2 GB
Entry: /open5gs_init.sh → /mnt/<nf>/<nf>_init.sh
```

All Open5GS NFs share the same image, distinguished by the `COMPONENT_NAME` environment variable. Each NF's config files and init scripts are mounted under `/mnt/<nf>/`.

### 5G Control Plane

| NF | COMPONENT_NAME | Ports | Dependencies | Description |
|----|---------------|-------|--------------|-------------|
| **AMF** | `amf` | 38412/sctp, 7777/tcp, 9091/tcp | nrf, scp, ausf, udm, udr, pcf, bsf | Access and mobility management |
| **SMF** | `smf` | 3868/sctp, 8805/udp, 2123/udp, 7777/tcp | nrf, scp, amf | Session management (DEPLOY_MODE=5G) |
| **NRF** | `nrf` | 7777/tcp | — | NF registration and discovery |
| **SCP** | `scp` | 7777/tcp | nrf | Service communication proxy |
| **AUSF** | `ausf` | 7777/tcp | nrf, scp | Authentication service |
| **UDM** | `udm` | 7777/tcp | nrf, scp | Unified data management |
| **UDR** | `udr` | 7777/tcp | nrf, scp, mongodb | User data repository |
| **PCF** | `pcf` | 7777/tcp, 9091/tcp | nrf, scp, mongodb | Policy control |
| **NSSF** | `nssf` | 7777/tcp | nrf, scp, mongodb | Network slice selection |
| **BSF** | `bsf` | 7777/tcp | nrf, scp, mongodb | Binding support |

### 5G User Plane

| NF | COMPONENT_NAME | Ports | Privileges | Description |
|----|---------------|-------|-----------|-------------|
| **UPF** | `upf` | 2152/udp, 8805/udp, 9091/tcp | NET_ADMIN, privileged, ip_forward | User plane forwarding |

### 4G EPC

| NF | COMPONENT_NAME | Ports | Dependencies | Description |
|----|---------------|-------|--------------|-------------|
| **MME** | `mme` | 36412/sctp, 2123/udp | hss, sgwc, sgwu | Mobility management (DEPLOY_MODE=4G) |
| **SGW-C** | `sgwc` | 2123/udp, 2152/udp | mme | Serving gateway control plane |
| **SGW-U** | `sgwu` | 2152/udp | sgwc | Serving gateway user plane (privileged) |
| **HSS** | `hss` | 3868/sctp | mongodb | User subscription data |
| **PCRF** | `pcrf` | 3868/sctp | mongodb | Policy and charging rules |

### Key Environment Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `COMPONENT_NAME` | NF name to start | `amf` |
| `DEPLOY_MODE` | Deployment mode (used by SMF/MME) | `5G` / `4G` |
| `MCC` | Mobile country code | `999` |
| `MNC` | Mobile network code | `70` |
| `UE_IPV4_INTERNET` | UE data network CIDR | `10.45.0.0/16` |

## Free5GC Network Functions

### Image Info

```
Image: free5gc/<nf>:v4.0.1  (per-NF image)
Size: ~150-200 MB each
Entry: ./<nf> -c ./config/<nf>cfg.yaml
Workdir: /free5gc
```

### 5G Control Plane

| NF | Image | Ports | Dependencies | Extra Env |
|----|-------|-------|--------------|-----------|
| **AMF** | `free5gc/amf:v4.0.1` | 8000/tcp, 38412/sctp | nrf | GIN_MODE=release |
| **SMF** | `free5gc/smf:v4.0.1` | 8000/tcp | nrf, amf | GIN_MODE=release |
| **NRF** | `free5gc/nrf:v4.0.1` | 8000/tcp | mongodb | DB_URI=mongodb://db/free5gc |
| **AUSF** | `free5gc/ausf:v4.0.1` | 8000/tcp | nrf | GIN_MODE=release |
| **UDM** | `free5gc/udm:v4.0.1` | 8000/tcp | nrf | GIN_MODE=release |
| **UDR** | `free5gc/udr:v4.0.1` | 8000/tcp | nrf, mongodb | DB_URI=mongodb://db/free5gc |
| **PCF** | `free5gc/pcf:v4.0.1` | 8000/tcp | nrf | GIN_MODE=release |
| **NSSF** | `free5gc/nssf:v4.0.1` | 8000/tcp | nrf | GIN_MODE=release |
| **CHF** | `free5gc/chf:v4.0.1` | 8000/tcp | nrf, mongodb | DB_URI=mongodb://db/free5gc |

### 5G User Plane

| NF | Image | Ports | Privileges | Description |
|----|-------|-------|-----------|-------------|
| **UPF** | `free5gc/upf:v4.0.1` | 2152/udp, 8805/udp | NET_ADMIN | Runs iptables rules before startup |

### TLS Certificates

All Free5GC SBI communication uses HTTPS. The certificate directory is mounted at `/free5gc/cert` (read-write mode; the NRF regenerates certificates on startup).

## RAN Components (Base Station & Terminal)

### docker_ueransim (5G NR)

```
Image: docker_ueransim:latest
Size: ~181 MB
Entry: /ueransim_image_init.sh
Workdir: /UERANSIM/build
```

Distinguished by `COMPONENT_NAME`:

| COMPONENT_NAME | Role | Start Command | Config Mount |
|---------------|------|---------------|--------------|
| `ueransim-gnb` | 5G base station (gNodeB) | `./nr-gnb -c ../config/ueransim-gnb.yaml` | `/mnt/ueransim` |
| `ueransim-ue` | 5G terminal (UE) | `./nr-ue -c ../config/ueransim-ue.yaml` | `/mnt/ueransim` |

**gNodeB key parameters (ueransim-gnb.yaml):**

| Parameter | Description | Default |
|-----------|-------------|---------|
| `mcc` / `mnc` | PLMN identity | Injected from MCC/MNC env vars |
| `nci` | NR Cell Identity | `0x000000010` |
| `tac` | Tracking Area Code | `1` |
| `linkIp` / `ngapIp` / `gtpIp` | gNB local IP | Injected from NR_GNB_IP |
| `amfConfigs.address` | AMF address | Injected from AMF_IP |
| `slices[].sst` | Network slice type | `1` |

**UE key parameters (ueransim-ue.yaml):**

| Parameter | Description | Default |
|-----------|-------------|---------|
| `supi` | User identifier (IMSI) | `imsi-999700000000001` |
| `key` | Permanent subscription key (KI) | Injected from UE1_KI |
| `op` / `opType` | Operator code | Injected from UE1_OP, type OP |
| `amf` | AMF authentication field | `8000` |
| `gnbSearchList` | gNB search list | Injected from NR_GNB_IP |
| `sessions[].apn` | PDU session APN | `internet` |

### docker_srslte (4G LTE)

```
Image: docker_srslte:latest
Size: ~4.28 GB
Entry: cd /mnt/srslte && /mnt/srslte/srslte_init.sh
Config target: /etc/srsran/
```

Distinguished by `COMPONENT_NAME`:

| COMPONENT_NAME | Role | Start Command | Description |
|---------------|------|---------------|-------------|
| `enb` | 4G base station (eNodeB) | `/usr/local/bin/srsenb` | S1AP connection to MME |
| `gnb` | 5G base station (srsRAN) | `/usr/local/bin/srsenb` | NGAP connection to AMF |
| `enb_zmq` | 4G base station (ZMQ) | `/usr/local/bin/srsenb` | ZeroMQ RF simulation |
| `ue_zmq` | 4G terminal (ZMQ) | `/usr/local/bin/srsue` | ZeroMQ RF simulation |
| `ue_5g_zmq` | 5G terminal (ZMQ) | `/usr/local/bin/srsue` | ZeroMQ RF simulation |

**eNodeB key parameters (enb.conf):**

| Parameter | Description | Default |
|-----------|-------------|---------|
| `enb_id` | eNB identifier | `0x19B` |
| `mcc` / `mnc` | PLMN identity | Injected from env vars |
| `mme_addr` | MME address | Injected from MME_IP |
| `gtp_bind_addr` | GTP bind address | Injected from SRS_ENB_IP |
| `s1c_bind_addr` | S1AP bind address | Injected from SRS_ENB_IP |
| `n_prb` | Number of physical resource blocks | `50` |

### docker_ueransim vs docker_srslte

| Dimension | docker_ueransim | docker_srslte |
|-----------|----------------|---------------|
| Radio access | 5G NR | 4G LTE (also 5G NR via srsRAN) |
| Image size | ~181 MB | ~4.28 GB |
| RF simulation | Built-in (no ZMQ needed) | Requires ZMQ mode |
| Config format | YAML | INI (conf) |
| Config mount | `/mnt/ueransim` | `/mnt/srslte` |
| UE connection | Auto-searches gNB | ZMQ direct to eNB |
| Recommended for | 5G SA testing | 4G EPS testing |

## Data / Storage Components

| Component | Image | Core | Description |
|-----------|-------|------|-------------|
| **MongoDB** (Open5GS) | `mongo:6.0` | open5gs | User subscription data, named volume `mongodbdata` |
| **MongoDB** (Free5GC) | `mongo:3.6.8` | free5gc | NF registration data, named volume `dbdata`, alias `db` |

## Networking Components

| Component | Description |
|-----------|-------------|
| **Bridge (L2)** | Logical bridge representing a single Docker network segment. Spawns no container; used only for topology wiring |
| **Ext DN** | External data network using the `network-multitool` image, used for connectivity testing |
